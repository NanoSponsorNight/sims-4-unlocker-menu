## 🧩 About

**The Sims 4 Companion** is a curated list of The Sims 4 open-source tools:

- **Overlays** — on-screen helpers, layout notes, household viewer, build-mode reference
- **Quality-of-Life Helpers** — catalog browser, trait notes, overlay notes
- **Research Notes** — build layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Household Viewer — review active sims and needs at a glance
- Relationship Notes — track family trees and social links
- Time Control Notes — pause and step time for study
- Speed Reference — compare game speeds side by side

### Wallhack
- Catalog Browser — browse build/buy items with notes
- Trait Catalog — organize traits and aspiration notes
- Custom Content Notes — keep track of installed CC

### Aimbot
- Build Mode Notes — segment study on any lot layout
- Floor Plan Reference — manual toggle for grid overlays
- Object Placement Notes — chain complex builds in the editor
